Run 3 remediation
-----------------
GitOps PR 997 removes only --speculative-adaptive from the native-MTP profile.
The fixed five-step native MTP configuration and its target/draft CUDA graphs
remain enabled. The default adaptive controller otherwise builds additional
1/3/7-step runtime states and graph families; those are unnecessary at the
profile's fixed concurrency of one and accounted for the post-graph headroom
loss observed above. This remediation deliberately retains the 511232-token
target and native-MTP KV pools. Served text and vision results must be appended
only after this profile passes warmup and real requests.
