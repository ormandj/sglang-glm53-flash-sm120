Root-cause source audit
-----------------------
The model uses:

  kv_cache_dim: 584 bytes/token/layer
  q head dim: 512
  index_topk: 2048
  index_kpool: 4
  runtime selected width: 2051 (2048 base + 3 live tail)

The inherited generic adapter calls the 656-byte GLM-NSA API. FlashInfer's
SM120 DSv4 API instead accepts a fixed 128-entry primary segment and a runtime
secondary segment. The v0.1.0-rc.9 adapter therefore uses 128 + 1,923 entries
and points both segments at the same physical packed KV cache.
