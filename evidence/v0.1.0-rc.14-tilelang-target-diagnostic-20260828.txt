  explicitly to bfloat16. That corrected pod booted with zero restarts.

Interpretation and disposition
  Changing the full-attention implementation from FlashInfer sparse MLA with
  FP8 KV to TileLang with BF16 KV does not restore correct target logits. The
  failure also reproduces through raw completion, so it is not a reasoning or
  tool parser presentation defect. Together with the prior Marlin, eager and
  production-kernel controls, this moves the leading fault boundary toward the
  checkpoint quantization/model-loading contract or a model-architecture path
  shared by every backend tested.

  v0.1.0-rc.14 is built but not qualified. Native MTP was deliberately not
  selected because target-only correctness is a prerequisite. The Deployment
  was scaled to zero after evidence capture. An independently produced pinned
  ModelOpt NVFP4 checkpoint is the next checkpoint-versus-runtime control.
